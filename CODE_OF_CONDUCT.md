# Code of Conduct

Memo Widget is a small open source project. The goal is to keep discussion practical, respectful, and focused on improving the app.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, especially when discussing bugs or review feedback.
- Keep reports specific and reproducible when possible.
- Avoid sharing private data, tokens, API keys, or personal information in public issues.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing another person's private information.
- Posting secrets, exploit details, or vulnerability proof-of-concepts in public issues.
- Repeated off-topic or bad-faith disruption.

## Enforcement

The maintainer may edit, hide, or remove comments and issues that violate this code of conduct. Security-sensitive reports should follow `SECURITY.md`.
